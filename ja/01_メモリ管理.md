# メモリ管理
ここでは私がメモリ管理で学んだ事を纏めています。

## 変数とは何か
まずは変数とメモリの関係からです。
こちらは学習前からなんとなく予想はついていましたが、
メモリ上に置いたデータを指すラベルです。

```rust
let x = 10;
```

のようにあったら

```
メモリ1000番地のデータ(10) -> x
```

のようになるイメージです。
このメモリの番地のことをアドレスと呼び、
また、そのアドレスを保持している値をポインタと呼びます。


## スタックとヒープ
変数で定義した値はメモリに置かれるわけですが、
そのメモリ領域はRustでは2種類あります。

それがスタックとヒープです。

### スタック
スタックは主に小さな固定サイズのデータが置かれます。
スタックは容量がヒープよりも少ないですが、その代わりに高速にアクセスできます。

ただし、「固定サイズ」であることが重要であり、
必ずしも小さいデータだけが置かれるわけではありません。

例えば

```rust
let big = [0u8; 100000];
```

のようなu8自体は小さくとも、大きな配列が置かれることもあります。

#### スタックのイメージ

```rust
let x = 5;
let y = 10;
```

と変数の宣言をしたら

```
┌───────┐
│y = 10 │
├───────┤
│x = 5  │
└───────┘
```

のようにスタックメモリに置かれます。
宣言し順番にスタックに積み重ねるように置かれていきます。
そして使い終わったデータは積み重なった上から順番に開放していきます。

これを「LIFO」というようです。
    Last in first out
の略です。

#### スタックが高速な理由
スタックはスタックポインタを移動するだけで確保・解放できるため高速です。

### ヒープ
ヒープは動的に容量を確保できるメモリです。
主にStringやVecなどの可変的な容量のデータが置かれます。
スタックより容量が大きいので大きなデータ向けなのですが、その代わりスタックよりもアクセス速度が低いです。

#### ヒープのイメージ
ヒープは宣言した変数の全てのデータが置かれているわけではありません。
ヒープにはStringやVecなどの巨大データの実データが置かれます。
そしてその位置やサイズの情報をスタックが変数の形で置かれます。

つまり
```rust
let x = String::from("Hello World");

println!("{}", x);
```
というコードがあった場合

```
[スタック]
┌─────────────────────────┐
│ヒープの先頭位置         │
│現在の長さ               │
│確保しているヒープの長さ │
└─────────────────────────┘

[ヒープ]
┌───────────────────┐
│H e l l o W o r l d│
└───────────────────┘
```

というデータ構成になります。

```rust
println!("{}", x);
```

でxにアクセスする際、
プログラムはまずスタックからxの情報を取り出し、
その中にあるヒープの先頭位置のデータにアクセスし、
現在の長さ分データを取り出します。

### メモリ確保はどうなっているのか
これはプログラム実行時にOSが割り当ててくれます。
```
高アドレス
┌───────────────┐
│スタック       │ (↓下方向に伸びる↓)
├───────────────┤
│               │
│               │
│               │
│               │
│               │
├───────────────┤
│ヒープ         │ (↑上方向に伸びる↑)
├───────────────┤
│グローバル変数 │
├───────────────┤
│コード領域     │
└───────────────┘
低アドレス
```
のようなイメージです。

### スタックフレーム
先ほど小さい固定長のデータは主にスタックに置かれると書きましたが、
このデータはスタックフレームという単位の中に置かれていくようです。

このスタックフレームとは何かというとこれは関数ごとに作成されるスタックの小さな領域のようなイメージです。

```rust
fn main() {
    let x = 10;
    let y = 10;
}

fn add() {
    let x = 10;
    let y = 10;
}
```
のような関数があれば、mainスタックフレームとaddスタックフレームが作られ、
それぞれ`x`や`y`のデータが置かれます。

### ヒープのメモリ確保
ヒープは動的な領域なので、足りなくなるとOSに追加の領域を要求します。
メモリ確保に失敗すると、エラーやプログラム終了などの処理になります。
Rustの標準環境では多くの場合プログラムが終了します。
